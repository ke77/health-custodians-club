# Dashboard handbook

For the Health Custodians Club executives. No technical knowledge needed.
The dashboard is at **healthcustodiansclub.com/admin** (or tap **Admin** in the website menu).

## Signing in
Enter your email. Then either:
- **Email me a sign-in code**: a 6-digit code arrives by email (check spam). Type it in. It lasts 10 minutes.
- **Use my password**: if you have set one under **Your account**.

Only emails an admin has added can sign in. Forgot your password? Use the code option and set a new one under Your account.

## Install it on your phone
Open **Your account → Dashboard app**.
- **Android**: tap **Install the app**.
- **iPhone**: in Safari tap **Share**, then **Add to Home Screen**.

## Applications
**Applications** lists everyone who has applied. Search by name, email, reference number or student ID, and filter by status, region, programme, institution or cohort. Open a person to read every answer, add private notes (only admins see them) and change their status. **Export CSV** downloads the list you are looking at.

### Changing a status and emailing the applicant
Pick a new status on the application. For **Accepted**, **Rejected** and **Waitlisted** a box opens showing the email the person will get. Leave **Email the applicant** ticked to send it with the change, or untick it to save the status quietly. The dashboard remembers who has been emailed, so nobody gets the same email twice. If an email fails, the status is still saved and you are told, so you can write to them yourself.

## Opening and closing applications
**Applications window**: switch applications open or closed, set the cohort (for example 2026/27) and an optional deadline. When closed, the apply page shows a waiting-list form instead.

## Waiting list
**Waiting list** shows who asked to be told when applications open. When you reopen applications, press **Notify** on the cohort: everyone not yet told gets an email with a link to apply. You can press it again later to reach anyone who joined since. It only works while applications are open and only for the current cohort.

## Enquiries
Messages from the contact form. Reply from your own email using the link, then mark it **handled** so the team knows.

## The website's content
- **Blog**: **New post**, write it, add a cover photo, then **Publish**. Until the first post is published the Blog page says "Coming soon". Unpublish to take a post down.
- **Leadership**: the Executive Committee, Board of Advisers and each region's head, with photos. Switch someone off to hide them without deleting.
- **Partners**: logos and links. Until one is published, the Partners page says the club is building partnerships.
- **Announcement banner**: a short message across the top of every page. Switch it off to hide it.
- **Admins**: add or remove people who can use the dashboard. You cannot remove yourself, and the last admin cannot be removed. When a new executive team takes over, add them here first, then remove the old ones.

## Who gets which notification
All three addresses end up in the club's shared inbox, so you can filter on the "To" address:
- **contact@healthcustodiansclub.com**: messages sent through the website's contact form.
- **info@healthcustodiansclub.com**: new membership applications. Applicants' replies to the club's emails also arrive here.
- **admin@healthcustodiansclub.com**: a notice whenever an admin is added or removed, saying who did it.

## Not in the dashboard
The FAQs, the contact email, phone numbers and social media links are part of the website's code. To change them, ask the developer.

## If something goes wrong
- **A sign-in code does not arrive**: check spam; wait a minute; try again. If it never arrives for anyone, email sending is not working (tell the developer).
- **An email did not send to an applicant**: the dashboard says so. Write to them directly from your own email, quoting their reference number.
- **The site is down or the dashboard will not load**: the free database sleeps if unused for a week; a daily automatic check normally prevents this. Tell the developer.
- **A page shows old content after an edit**: refresh the page. If it is still old, tell the developer.
